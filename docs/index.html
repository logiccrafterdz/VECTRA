VECTRA: Observable Microstructure Pressure & Exhaustion Engine

VECTRA is a deterministic, single-pass, event-driven quantitative research engine written in standard C++20. It extracts strictly observable quote phenomena—wall-clock log displacements, movement persistence, per-tick price response, multi-scale path efficiency, and intra-window deceleration—and evaluates whether transparent mathematical rules survive bid/ask spread crossing, round-trip commission, slippage, and latency on real institutional EUR/USD tick streams.

Epistemic Discipline: VECTRA contains no machine learning, no neural networks, and no latent behavioral attributions (such as "stop cascades" or "forced liquidations"). All outputs in [0, 1] are explicitly reported as uncalibrated scores alongside 5-bin Brier reliability tables and autocorrelation-robust non-overlapping horizon block Student t-statistics.

1. System Architecture & Single-Pass Causal Pipeline

Strict separation of quote validation, wall-clock feature extraction, scoring, risk gating, and simulated venue execution

Every incoming tick is processed in a strictly causal single pass. Invalid or crossed-spread quotes are rejected at the boundary before reaching the rolling state windows, ensuring that bad ticks never corrupt volatility or displacement estimates.

6. Mathematical Model & Formula Specification

Every observable feature, regime filter, exhaustion component, and risk equation implemented in C++20

1. Fixed-Point Price & Wall-Clock Log Displacements

Price = round(decimal * 10^7) [int64_t] r_W(t) = ln( mid(t) / mid(t - W_ns) )

Prices are stored as exact 64-bit scaled integers (10^-7 precision). Displacements are anchored to provider timestamps (W_short = 120s, W_mid = 240s, W_long = 720s) via binary search over the timestamp deque.

2. Multi-Scale Block Regime Efficiency

regime_efficiency = |r_long(t)| / sum_{k=1..K} |r_block_k(t)|

Partitions the long window into K contiguous sub-blocks of length W_short. By the triangle inequality, regime_efficiency in [0, 1]: values near 1 indicate directional trend alignment; values near 0 indicate mean-reverting chop.

3. Scale-Invariant Inter & Intra-Window Deceleration

decel_inter = sign(r_short) * (r_prev - r_short) / (sigma * sqrt(2*n)) decel_intra = sign(r_short) * (r_older_half - r_recent_half) / (sigma * sqrt(n)) deceleration = clamp(max(decel_inter, decel_intra), -1, 1)

Detects momentum slowdown both relative to the prior short window and within the current short window (comparing the first 60s to the latest 60s).

4. Composite Movement-Exhaustion Score

E(t) = (w_ext * ext + w_dec * decel_+ + w_fade * fade + w_qual * pen) / sum(w)

Combines volatility-normalized extension (|z_short| / z_norm), positive deceleration, per-tick response fade, and elevated-spread penalty into a bounded hypothesis score in [0, 1].

5. Transparent Signal Scoring & Expected Move

S_cont = (1 - E) * g_ext * max(0, persistence) S_rev = E * g_ext * (1 - max(0, persistence)) E[move_log] = clamp(dir * S_kind * scale_kind * |r_short|, -max_move, +max_move)

Normalizes expected log move across signal kinds via continuation_move_scale and reversal_move_scale before converting to price units for the risk engine.

6. Round-Trip Cost Gate & Non-Overlapping t-Stat

Cost_RT = spread + 2 * (commission + slippage) Edge = mid * |E[move_log]| - Cost_RT >= min_expected_edge t_stat = mean(net_spread_block) / (std_block / sqrt(M_blocks))

Requires every entry to clear full entry+exit transaction costs plus min_expected_edge, subject to a 180s wall-clock cooldown.
